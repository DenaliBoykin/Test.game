# Mini Runner Game

A very simple 2D endless runner game.

## Controls
- Spacebar = Jump
- Spacebar after game over = Restart

## Features
- Simple 2D canvas game
- One-button jump control
- Randomly generated obstacles
- Score counter
- Speed increases over time

## Run it
Just open `index.html` in a browser.

## Notes
This is base starter code meant for expanding inside Codex.
You can later add:
- sprites
- sound effects
- start menu
- better obstacle variety
- mobile support
